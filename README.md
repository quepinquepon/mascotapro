# MascotaPro – Organizador de Mascotas (PWA) v1.1

Aplicación web progresiva instalable en el celular desde Chrome.
Más completa y superior a las apps básicas de organización de mascotas.

## Características

### Implementado
- Instalación como app nativa desde Chrome
- Sistema de licencias con claves (PET-XXXX-XXXX-XXXX)
- Generador de claves integrado (en Ajustes)
- Ficha completa de mascotas
- Vacunas con fecha, próxima dosis, veterinario y recordatorio automático
- Gastos con categorías, monto, fecha y total
- Recordatorios con notificaciones del sistema
- Mascota Perdida: genera QR real + enlace para compartir / NFC
- Modo oscuro
- Exportar / Importar datos (JSON)
- Funciona offline
- Actualizaciones automáticas al subir cambios a GitHub Pages

## Cómo instalar (usuario final)

1. Abrí el link de GitHub Pages en Chrome.
2. Tocá “Instalar aplicación” o “Agregar a la pantalla de inicio”.
3. Al abrir, te pide la clave de licencia.
4. Ingresá la clave que te dio el vendedor.

## Cómo generar claves de licencia (vos)

Método 1 – Desde la app (recomendado)
1. Activá cualquier licencia válida.
2. Andá a Ajustes.
3. Abajo está el “Generador de claves”.
4. Tocá “Generar nueva clave” → se copia al tocar.

Método 2 – Consola del navegador
generateLicenseKey()

## Publicar en GitHub Pages

1. Creá un repositorio (ej: mascotapro-app).
2. Subí todo el contenido de esta carpeta a la raíz.
3. Settings → Pages → Deploy from branch main → / (root).
4. En 1-2 minutos tenés el link:
   https://tuusuario.github.io/mascotapro-app/

## NFC / Mascota Perdida

- Generás un QR desde la sección “Perdida”.
- Lo imprimís o lo grabás en un tag NFC barato.
- Quien lo escanee ve el enlace de reporte.
- La localización es gratuita porque depende de que alguien escanee y te contacte (no es GPS en tiempo real).
